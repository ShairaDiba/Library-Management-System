# 📚 Library Management System

A web-based Library Management System built with PHP that allows librarians and users to manage books, members, and borrowing records efficiently.

---

## 🔧 Tech Stack

- **Language:** PHP
- **Frontend:** HTML, CSS
- **Database:** MySQL

---

## ✨ Features

- Add, update, and delete books
- Manage library members
- Track borrowed and returned books
- Search books by title or author
- Admin dashboard for library staff

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ShairaDiba/Library-Management-System.git
   ```

2. Move the project folder to your local server directory (e.g. `htdocs` for XAMPP)

3. Import the database:
   - Open `phpMyAdmin`
   - Create a new database named `library_db`
   - Import the `.sql` file from the project folder

4. Open your browser and go to:
   ```
   http://localhost/Library-Management-System
   ```
